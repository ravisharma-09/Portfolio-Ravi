LessonLingo

Offline Lecture Translator

by Ravi Sharma · Team project · October 2026

What it is

LessonLingo turns English lectures into Hindi and Kannada subtitles and dubbed audio, and it keeps working fully offline after the first model download.

What Ravi Sharma built

  • Built the step-by-step web interface for the translation workflow.
  • Added automated tests for the pipeline.
  • Made Markdown lecture notes translate while preserving headings, tables and code blocks.

Tech

  • Python
  • pytest
  • Offline speech + translation models
  • Web UI
