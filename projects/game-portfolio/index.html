What it is

Ravi Sharma's portfolio is a 2D game: walk around a room, open the hallway, print the resume in the archive, follow the journey map and play Coin Rush in the arcade.

What Ravi Sharma built

  • Designed and built the whole game: room, hallway, archive quest, journey map and arcade.
  • Custom animations, keyboard and touch controls, and optimised assets for fast loads (about 35 hours of work from scratch).

Tech

  • JavaScript
  • Phaser.js
  • HTML5 Canvas
  • CSS
